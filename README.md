# מזרק

תוכנה למחשב למשיכה אוטומטית של תנועות מהבנקים וחברות האשראי בישראל, וייצוא שלהן לתקציב
(Google Sheets, YNAB, אקסל או JSON).

הפרטים של הבנקים נשמרים רק במחשב שלך, מוצפנים.

## מקור

מזרק מבוסס על [כספיון (Caspion)](https://github.com/brafdlog/caspion) בקוד פתוח, ברישיון MIT,
ועל הספרייה [israeli-bank-scrapers](https://github.com/eshaham/israeli-bank-scrapers).
הערת הזכויות המקורית נשמרת בקובץ `LICENSE`.

## הרצה למפתחים

```bash
yarn install
yarn watch
```
